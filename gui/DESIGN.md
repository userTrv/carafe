# Облик carafe

Правила для всего, что рисует GUI. Новый экран или компонент берёт значения отсюда, а не придумывает
свои. Визуальная система основана на части B скилла `landing-page-design` из
[elayadesign/ai-design-skills](https://github.com/elayadesign/ai-design-skills) (MIT) и подогнана
под настольное приложение. Макет: холст «Редизайн carafe» у владельца.

## Идея

Цвет экрану дают обложки игр, интерфейс вокруг них монохромный и плоский. Один акцент, янтарный
`#E8B04B` («жидкость в графине»): прогресс, активные переключатели, знак. Технические данные
(движок, SDK, состояние облака) набраны моноширинным шрифтом, как этикетка на бутылке.

## Шрифты

- **Geist** — весь интерфейс. **Geist Mono** — только данные: версии, appid, размеры, статусы.
- Оба лежат в приложении (OFL 1.1, пакеты `@fontsource/geist`, `@fontsource/geist-mono`, подмножества
  latin и cyrillic); из сети ничего не грузится, CSP строгий.
- Без курсива и без веса 900. Заголовки — 600 или 700.
- Размеры только по шкале: 12/16, 14/20, 16/24, 18/28, 20/28, 24/32, 30/36, 36/40, 48, 60, 72, 96
  (размер/интерлиньяж; от 48 интерлиньяж 1). Промежуточных значений нет.
- Кнопки: основные 16px 600, мелкие 14px 600.
- `text-wrap: balance` у заголовков, `text-wrap: pretty` у текста. Заголовки — с заглавной только
  первое слово.

## Цвета

| Токен | Значение | Где |
|---|---|---|
| `--bg` | `#000000` | фон окна |
| `--surface` | `#181818` | карточки, панели |
| `--surface-2` | `#1F1F1F` | строки внутри панелей |
| `--surface-3` | `#272727` | кнопки второго плана, дорожки прогресса |
| `--line` | `#313131` | рамки, разделители, выбранная вкладка |
| `--plate` | `#131209` | подложка иконки |
| `--text` | `#F2F2F2` | основной текст |
| `--text-2` | `#B4B4B4` | второстепенный |
| `--text-3` | `#9B9B9B` | подписи, метки |
| `--accent` | `#E8B04B` | прогресс, включённое, знак |
| `--ok` | `#7BC67E` | «идёт» |

- Фоны всегда плоские, без градиентов. Единственный градиент — на тексте больших заголовков:
  слева направо `#FFFFFF` → `#9B9B9B`.
- Рамка у карточки либо со всех сторон, либо нет совсем.
- Статус не только цветом: рядом всегда слово или метка (`D3DMETAL`, `EAC`, `ПРОВЕРИТЬ`).

## Отступы и скругления

- Отступы только из ряда 0, 2, 4, 8, 12, 16, 24, 32, 40, 48, 64, 80, 96.
- Основная кнопка: 12px × 24px (в окне приложения кнопка должна быть не ниже 44px).
- Скругления: 8, 12, 16, 24, 32. Вложенное: `внутреннее = внешнее − зазор`, если зазор меньше 32 и
  результат больше 2. Пример: панель 24 с отступом 8 → строка внутри 16.
- Иконка приложения: сетка macOS, поле 824 в холсте 1024 (по 100 с каждой стороны), радиус 185.

## Иконки

- Phosphor (MIT), штрих 1.8 на сетке 24, без заливки; кнопки только с иконкой получают `aria-label`.
- Знак carafe — графин с янтарной жидкостью (`gui/ui/brand/mark.svg`). Меньше 24px — сплошной силуэт
  с линией уровня (`mark-small.svg`).

## Движение

- Кривая `cubic-bezier(0.22, 1, 0.36, 1)`: 500 мс для положения и раскладки, 300 мс для цвета и
  прозрачности, не короче 200 мс. Стандартные `ease`/`linear` не использовать.
- Анимируются только `transform` и `opacity`.
- `prefers-reduced-motion`: вместо движения — только смена прозрачности.
- Обложки при наведении поднимаются на 8px. Кнопки при нажатии — `scale(0.98)`.
- Запуск игры: кнопка «Играть» превращается в полоску из четырёх этапов (облако, мост, движок,
  игра), каждый этап заполняется по порядку.

## Навигация и раскладка

- Сверху по центру компактная плавающая панель: полупрозрачная `--surface` с размытием 20px, рамка
  `--line`, радиус 16. В ней разделы, мини-прогресс загрузки и аккаунт со скрытым Steam ID
  (`7656…4412`).
- Контент не шире 1248px. Обложки — сетка 2:3, радиус 16, промежуток 24.
- Библиотека — одна сетка на все игры. Над ней фильтры («Все» / «Установлено», «Для Mac») и поиск
  (⌘F). Не установленная игра — обложка чёрно-белая; пока качается, цветная копия поднимается снизу
  по проценту. Сборки — значками рядом с названием: яблоко (нативно), окно (Windows через carafe).

## Состояния

У каждого элемента есть наведение, нажатие, видимый фокус (`outline: 2px solid var(--text)`,
отступ 2px), загрузка (скелетон по форме настоящего блока, не крутилка), пустое состояние
(собранный экран с одним действием) и ошибка (на месте, по делу: что не вышло и что сделать).

## Текст

- Показывать, а не объяснять: короткие подписи, без абзацев-пояснений.
- Без дефисов внутри фраз и без «висячих» последних слов.
- Сообщения спокойные и конкретные: «Сохранения загружены в Steam», «Не хватает 3.1 GB на
  Macintosh HD». Без восклицательных знаков.
